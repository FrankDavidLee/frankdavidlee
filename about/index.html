About me

Frank David Lee · AI Engineer & Senior Fullstack Developer · Hamburg, Germany

I'm a fullstack developer with more than ten years of experience – from frontends for communication and embedded systems to browser gaming platforms and my own AI products. My core is TypeScript with Angular and Node.js; since 2025 that includes Python for machine learning, and since 2026 React/Next.js, Java and Spring Boot.

In 2025 I trained as a Data Scientist at Université Paris 1 Panthéon-Sorbonne with Liora (formerly DataScientest), and building on that, completed the Machine Learning Engineer (RNCP Level 7) and MLOps certificates in January 2026 – with Python, PyTorch, TensorFlow, MLflow, CI/CD and model serving. Since then I've been building LLM products that work beyond the demo: Arbeitseule has been in production on AWS since September 2026 – with a cost budget, versioned AI scores, backups to S3 with restore drills, CloudWatch monitoring, deployments via GitHub Actions and legal texts that move with every feature. For heyAppa, the AWS infrastructure is defined as code in Terraform.

I orchestrate my own development with AI agents. For that I built App-Leitstand: approvals bound to content and source revision, an MCP server for Claude Code and a LangGraph pilot. I use AI where it creates value – and I build the cost side first.
