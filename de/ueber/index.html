Über mich

Frank David Lee · AI Engineer & Senior Fullstack Developer · Hamburg

Ich bin Fullstack-Entwickler mit über zehn Jahren Erfahrung – vom Frontend für Kommunikations- und Embedded-Systeme über Browser-Gaming-Plattformen bis zu eigenen KI-Produkten. Mein Kern ist TypeScript mit Angular und Node.js; seit 2025 gehört Python für Machine Learning dazu, seit 2026 React/Next.js, Java und Spring Boot.

2025 habe ich mich an der Université Paris 1 Panthéon-Sorbonne mit Liora (ehemals DataScientest) zum Data Scientist weitergebildet und darauf aufbauend im Januar 2026 die Zertifikate Machine Learning Engineer (RNCP Level 7) und MLOps abgeschlossen – mit Python, PyTorch, TensorFlow, MLflow, CI/CD und Model Serving. Seitdem baue ich LLM-Produkte, die nicht nur in der Demo funktionieren: Arbeitseule läuft seit September 2026 in Produktion auf AWS – mit Kostenrahmen, versionierten KI-Bewertungen, Backups nach S3 mit Restore-Probe, Monitoring mit CloudWatch, Deployments über GitHub Actions und Rechtstexten, die mit jeder Funktion mitziehen. Für heyAppa liegt die AWS-Infrastruktur als Code in Terraform.

Meine eigene Entwicklung orchestriere ich mit KI-Agenten. Dafür habe ich den App-Leitstand gebaut: Freigaben, die an Inhalt und Quellstand gebunden sind, ein MCP-Server für Claude Code und ein LangGraph-Pilot. KI setze ich dort ein, wo sie Wert schafft – und baue die Kostenseite zuerst.
